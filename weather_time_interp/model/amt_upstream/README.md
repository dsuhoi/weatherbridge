# AMT Upstream Components

These modules are adapted from
[MCG-NKU/AMT](https://github.com/MCG-NKU/AMT), commit
`70f988fbfc0d3d458beba1ee49caf876e57968fe`.

Changes are limited to package-relative imports, configurable field-channel
counts, and periodic-longitude weather-field warping. The upstream
Attribution-NonCommercial 4.0 license is retained in `LICENSE`.

Citation:

> Li et al. "AMT: All-Pairs Multi-Field Transforms for Efficient Frame
> Interpolation." CVPR 2023.
