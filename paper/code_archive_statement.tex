Source code, experiment configurations and figure-generation scripts are
available at \url{https://github.com/dsuhoi/weatherbridge};
version 1.0.0 identifies the code supplied with this study
\cite{sukhorukov2026weatherbridgecode}.
The repository includes metric summaries and file provenance.
The accompanying model archive provides the ERA5-trained WeatherBridge
checkpoints for 6 h and 12 h intervals and the five learned 6 h comparators,
with normalisation, static fields and an example ERA5 window.
Other 12 h comparator, full-query control and HRES-adapted checkpoints
are not included in this archive.
Full-year inference requires the external datasets described above;
redrawing figures from stored scores does not rerun inference.
